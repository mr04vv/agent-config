# Favorite Skills

ユーザーがお気に入りとして登録しているスキルの一覧を表示するためのスキル。
このスキルが呼び出されたら、下記の一覧をそのままユーザーに提示すること。個別のスキルを勝手に起動しないこと。

## お気に入りスキル一覧

| スキル | 用途 |
| --- | --- |
| `html` | 概念・仕組み・調査内容を、HTML による視覚的な説明ドキュメントとして作成・編集する。 |
| `quizzing` | 計画・実装・コードベースについてユーザーに問題を出し、自分の言葉で説明できるまで理解を確認する。明示的呼び出し専用。 |
| `grilling` | 計画や設計について、共通理解に達するまでユーザーを徹底的に質問攻めにする（ビルド前のストレステスト）。 |
| `tutoring` | 計画・実装・コードベース・トピックについて、ユーザーが本当に理解するまで段階的に指導する。明示的呼び出し専用。 |
| `paper-details` | 学術論文の詳細な Markdown 解説を作成する（批評ではなく忠実な記述が目的）。 |
| `ponytail` | 実際に動く最もシンプル・最小限の解決策を強制する。YAGNI・標準ライブラリ優先で過剰実装を避ける（lite / full / ultra の強度指定あり）。 |

## 使い方

一覧を提示したうえで、ユーザーがどれを使いたいか尋ねること。特定のスキルの利用を求められたら、対応するスキルを起動する。
